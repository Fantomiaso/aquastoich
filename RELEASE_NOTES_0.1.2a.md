# AquaStoich 0.1.2a · Testing / Тестирование / Testphase / En pruebas

> **Unsigned testing release.** Windows and macOS packages are not digitally signed or notarized. Download them only from this official `Fantomiaso/aquastoich` release page.

## English

AquaStoich 0.1.2a is a testing release. It keeps the calculator and measurement-analysis behaviour of 0.1.1a while improving release transparency and multilingual documentation.

The project is free and noncommercial. It has no budget and no intention of paying platform fees for code-signing certificates or notarization of software that should remain free. Windows SmartScreen or macOS Gatekeeper may therefore require explicit approval on first launch. Linux AppImage/DEB and macOS x64/ARM64 launchability were checked on clean GitHub-hosted systems.

Every README now contains a dated version history with links to 0.1.2a, 0.1.1a, and 0.1.0a. Detailed changes remain available in the language-specific changelogs.

[English instructions](README.md) · [Changelog](CHANGELOG.md) · [License](LICENSE.md)
